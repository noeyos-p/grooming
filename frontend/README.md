# Grooming Style — Frontend

Next.js 14+ (App Router) + TypeScript + Tailwind CSS + shadcn/ui 기반 프론트엔드.

---

## 설치 및 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
```

---

## 환경변수 (`frontend/.env.local`)

```
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=
```
